# Rendez-vous avec les enseignants

Établissement fictif, document de démonstration.

## 1. Permanences

Chaque enseignant tient une permanence d'une heure par semaine dans son bureau. Les horaires figurent dans son agenda sous l'intitulé « Permanence ».

## 2. Prendre rendez-vous

Un étudiant peut prendre rendez-vous avec un enseignant pendant une permanence de celui-ci, directement depuis l'assistant de l'école.

Règles :
- un rendez-vous dure de 15 à 30 minutes ;
- il doit se situer entièrement dans le créneau de permanence ;
- deux rendez-vous ne peuvent pas se chevaucher dans une même permanence ;
- l'objet du rendez-vous est indiqué en une phrase.

En dehors des permanences, l'étudiant écrit à l'enseignant ; c'est l'enseignant qui propose alors un créneau.

## 3. Annulation

Un étudiant qui ne peut pas venir annule son rendez-vous dès que possible, afin de libérer le créneau.
