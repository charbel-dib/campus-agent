# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to the author through
[LinkedIn](https://www.linkedin.com/in/charbel-dib7) or the e-mail shown on the GitHub profile, with
the steps to reproduce. You will get an answer within a week, and a fix or a mitigation before any
public disclosure.

## What is in scope

The code in this repository and the public demo at https://agent-campus.onrender.com. The demo runs a
fictional school: its people and data are generated, there is no personal data to protect, but the
demo's API key and budget are. Please keep tests of the public demo within its per-visitor quota.
